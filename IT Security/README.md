# CyberQuest — IT Security Exam Learning Hub

Open `index.html` in Chrome/Edge/Firefox. No installation or build step is required.

Features:
- 20 LAQs from the uploaded syllabus
- Engineering-oriented explanations
- Real-world scenario framing
- Exam Mode for 10–15 mark answers
- Technical diagrams
- Quick checks and XP
- Search/filter/progress tracking
- Print/save as PDF
- Responsive mobile/desktop UI
